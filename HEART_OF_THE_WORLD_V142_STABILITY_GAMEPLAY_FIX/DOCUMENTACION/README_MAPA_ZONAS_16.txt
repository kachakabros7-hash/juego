MAPA v16 - MISHA: ADVENTURE

Se implementó una estructura visual inspirada en mapas de metroidvania:
- 12 ZONAS GRANDES, cada una con un color propio.
- Cada zona contiene varias mini-zonas/habitaciones representadas dentro de su región.
- Las conexiones entre regiones se muestran como rutas.
- Las zonas no descubiertas permanecen atenuadas.
- La zona actual tiene un marcador animado.
- Muestra iconos de enemigos, recompensas, habilidades, checkpoint y espacio para jefe.
- Se agregó un MINIMAPA fijo durante la partida.
- La tecla M abre el mapa grande y oculta temporalmente el minimapa.
- El mapa grande pausa el juego mientras está abierto.
- M vuelve a cerrar el mapa y reanuda la partida.
- C centra la vista en la zona actual; rueda/+/− controlan el zoom.

NOTA: las mini-zonas dibujadas son la estructura visual del mapa. Las escenas jugables existentes siguen siendo las habitaciones actuales del prototipo; no se crearon 40+ escenas nuevas automáticamente para no romper las conexiones existentes.

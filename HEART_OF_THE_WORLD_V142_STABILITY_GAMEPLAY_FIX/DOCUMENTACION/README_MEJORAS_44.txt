MISHA: HOLLOW REALM — v44

Exploración, secretos y rutas alternativas.

Cambios principales:
- Salidas hacia habitaciones secretas con visual de pared falsa y grietas sutiles.
- Las entradas ocultas se revelan visualmente cuando Misha se acerca.
- Las habitaciones secretas reciben un atajo adicional hacia su sala de recompensa.
- Los atajos de recompensa están vinculados a una habilidad concreta por región.
- Las salas de recompensa reciben una reserva de monedas única por habitación.
- Se mantiene el sistema de guardado y las recompensas permanentes existentes.
- No se modifica el movimiento, salto, dash ni ataque del jugador.
- Se mantiene la estructura de 60 habitaciones.

Nota: el proyecto no se pudo ejecutar con el editor Godot en este entorno; se realizaron comprobaciones estructurales y de referencias.

HEART OF THE WORLD - V133

Se integraron al Player las hojas de sprites del paquete Luneblade - Little Axion (Free).
Animaciones incluidas: idle, run, jump, fall, landing, attack_1, attack_2, dash, death y hurt.

Controles automáticos:
- Quieto: idle
- Movimiento A/D: run
- SPACE: jump; caída: fall; aterrizaje disponible
- J: attack_1 / attack_2 mediante el sistema de ataque existente
- SHIFT: dash
- Daño: hurt
- Muerte: death

Se conservaron mapa, cámara, colisiones, hitboxes, controles y sistemas existentes.
No se integró ningún video.

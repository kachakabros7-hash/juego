Misha Hollow Realm — V59

Pulido de jugabilidad base para Z01-Z04.
- Movimiento: velocidad, aceleración y fricción reajustadas.
- Salto: gravedad y salto afinados para control más consistente.
- Dash: ligeramente más largo, rápido y con recuperación más limpia.
- Cámara: suavizado aumentado para las zonas grandes y verticales.
- Se conservan las escenas, sprites, animaciones y habilidades existentes.

Ruta objetivo de prueba:
Z01 -> Z02 -> Z03 -> Z04 -> Z03 -> Z02 -> Z01

Nota: esta versión fue validada estructuralmente; el entorno de trabajo no dispone del ejecutable de Godot para una prueba de ejecución.
